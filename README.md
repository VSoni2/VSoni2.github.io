# vsoni2.github.io

My personal portfolio, live at **[vsoni2.github.io](https://vsoni2.github.io)**

I'm Vishit Soni, an embedded firmware & FPGA engineer, open to roles across Canada and the USA. I currently work on flight firmware for the [RADICALS](https://radicalsmission.ca) satellite mission, a Canadian Space Agency low-Earth-orbit mission investigating the impact of space radiation on Earth's climate (target launch 2027).

## About this site

Hand-built with plain **HTML, CSS, and JavaScript**. No frameworks, no libraries, no build step. The theme borrows from the tools I work with every day:

- **Boot-sequence intro:** a firmware-style boot log that plays once per session
- **Signal-trace canvas:** animated oscilloscope/logic-analyzer waveforms in the hero that react to your cursor
- **Signal-bus navigation:** a progress rail that fills and lights up section nodes as you scroll
- **Register-map skills:** capabilities laid out the way I'd read a datasheet
- Scroll-driven reveals, an animated timeline, stat counters, and 3D-tilt project cards

Accessibility isn't an afterthought: everything respects `prefers-reduced-motion`, works without JavaScript, and keeps visible keyboard focus.

## Structure

```
index.html   - content and structure
styles.css   - theme, layout, animations
app.js       - canvas, boot sequence, scroll effects
```

## Run locally

Clone the repo and open `index.html` in a browser. That's it.
